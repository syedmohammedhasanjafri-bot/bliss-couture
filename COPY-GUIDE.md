# BLISS COUTURE — Copy & Voice Guide

## Brand Voice

Bliss Couture speaks as a **heritage Indian bridal couturier** from Vadodara, Gujarat. Not a Western luxury brand. Not a tech startup. Not a generic fashion label. The voice is:

- **Reverent** — speaks of craft with deep respect, never casual
- **Precise** — uses exact craft terminology, never vague descriptors
- **Measured** — confident without being boastful, elegant without being pretentious
- **Rooted** — grounded in Vadodara, Gujarat, and Indian bridal tradition
- **Personal** — addresses the bride directly, warmly, as family would

---

## Mandatory Craft Vocabulary

Always use these real Indian embroidery and textile terms (never substitute with generic English):

| Term            | Meaning                                                        |
|-----------------|----------------------------------------------------------------|
| **Adda**        | The wooden embroidery frame on which fabric is stretched       |
| **Zardozi**     | Metallic coil thread embroidery using gold/silver wire         |
| **Resham**      | Pure twisted silk thread used in surface embroidery            |
| **Dabka**       | Coiled metallic wire, thicker than Zardozi, for raised motifs  |
| **Kundan**      | Uncut polki stones set in gold foil, pressed into Lac beds     |
| **Kundan Jaal** | A mesh/net pattern created with Kundan stone placement         |
| **Chandi Zari** | Real silver wire woven into brocade borders on handlooms       |
| **Kali**        | Individual panel of a lehenga (e.g. 24-Kali = 24 panels)      |
| **Ghera**       | The circumference/flare of the lehenga skirt                   |
| **Latkan**      | Decorative tassels/hangings at the lehenga waistband           |
| **Karigar**     | Master artisan/craftsperson                                     |
| **Shisha**      | Small mirrors hand-set into embroidery                         |
| **Motif Sheet** | Hand-drawn design template for embroidery placement            |

## Price & Number Formatting

- Use ₹ (Indian Rupee) symbol, never $
- Use lakh notation: ₹1,00,000 (not ₹100,000)
- Use Indian number grouping: 22,000+ (not 22K)
- Craft hours: always written as "1,200+" or "3,600+" (never approximated to "thousands")

## Copy Don'ts

| DON'T                                              | DO INSTEAD                                          |
|----------------------------------------------------|-----------------------------------------------------|
| "Luxury at its finest"                             | Name the specific craft or fabric                   |
| "Handmade with love"                               | "Hand-couched on the Adda frame"                    |
| "Artisanal craftsmanship"                          | "Three-generation Karigar lineage"                  |
| "Bespoke experience"                               | "Private consultation with motif sketching"         |
| "Premium quality"                                   | "24-Kali ghera, Varanasi silk, Zardozi and Dabka"   |
| "World-class design"                               | "Vadodara atelier" (be specific, be rooted)         |
| "Shop now"                                          | "Reserve This Masterpiece" or "Book Consultation"   |
| "Sign up"                                           | "Request Private Consultation"                      |
| Generic testimonials                                | Specific craft processes and material details        |
| "Our team of skilled artisans"                     | "Twelve master Karigar families"                    |

## Section-Specific Copy Notes

### Overture (Hero)
- Location stamp: "Vadodara, Gujarat — Est. MMXVIII"
- Headline: Two lines, second line italic
- Subtext: Max 25 words, must mention Adda frame and at least two embroidery techniques

### Atelier
- Each craft card names a specific technique with its Indian name
- The editorial quote should feel like it belongs in a Sabyasachi or Tarun Tahiliani monograph
- No more than 3 sentences per card

### Runway
- Each look name is a color + technique identifier (e.g. "Rani Pink Silver Zardozi")
- Descriptions must mention specific materials, techniques, and occasions
- Spec tables use real garment terms (Ghera, Kali count, Craft Hours, Base Fabric)
- The flagship (Sindoor Mahal) gets extended description and a dedicated CTA

### Artisans
- Stats use real numbers (12 families, 3,600 peak hours, 24 Kali panels)
- Process steps use Roman numerals (I, II, III, IV)
- Each step mentions specific materials, locations, or techniques

### Ledger (Contact)
- Form is warm and inviting, not transactional
- "Your Vision" textarea prompt is specific to bridal context
- NRI note addresses international brides directly with practical service details
